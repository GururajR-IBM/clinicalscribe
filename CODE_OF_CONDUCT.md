# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Report unacceptable behaviour to **Gururajraibagi7@gmail.com**. All reports are confidential.

## TL;DR

- Be kind. Assume good intent.
- No harassment, no discrimination, no doxxing, no clinical advice in issues.
- Maintainers reserve the right to remove comments and ban repeat offenders.
